# Formats

All 9:16, 1080x1920, 30 fps. Times are rough targets, not hard limits.

## Education (Style A)
```
0–2s    HOOK      the claim / promise ("6 objections dalam 60 saat")   push-in, big keyword
2–5s    SETUP     why it matters                                        B-roll
5–50s   POINTS    1 … N: header top-left for each, keyword pop per idea, B-roll on concrete nouns
last 3s CTA       "follow untuk part 2" / "comment X"                    Follow-button pop
```
- A numbered talk gets `headers` ("1 I NEED TO THINK ABOUT IT"). A countdown gimmick (timer) only if the
  talk itself says "dalam 60 saat".
- Logos/icons pop over the head when a brand or object is named (icon in a yellow dashed box).

## Do & Don't (Style A)
```
HOOK  → "Jangan buat ni…"
DON'T → label "❌ DON'T" top-left in red (#FF3B30), slightly desaturated grade on this section
TURN  → riser SFX, punch-in, whoosh
DO    → label "✅ DO" in green (#34C759), normal grade
CTA
```
Several pairs → repeat DON'T/DO with the pair number in the label ("❌ DON'T #2").

## Before / After (Style A, B for lifestyle/visual results)
```
HOOK   → the result first (show 1 s of AFTER), then "macam mana?"
BEFORE → label "BEFORE", B-roll/photos of the before state
TURN   → wipe or slider transition (left→right), whoosh + pop
AFTER  → label "AFTER" in yellow, the payoff keyword big
CTA
```
If the user has before/after photos, show them side by side (split screen) at the turn for 1.5 s.

## Vlog (Style B)
```
0–2s   HOOK    big condensed title over the most cinematic shot ("Do you wanna make / BETTER")
body   STORY   B-roll-led, cut every ~2 s, small serif subtitles only, title words for chapter beats
end    PAYOFF  one big title word ("FOREVER", "UP"), music hit on the last line
```
- Talking-head shots are interleaved, not the base layer. Use B&W for reflective moments.
- Whip/zoom-blur transitions between locations.
